This rehub is locked

rehub is running, but this browser does not have its private link. That is on purpose: it keeps other people who use this computer out.

  • Find the link. It is printed in the terminal where you ran rehub web, and ends in ?token=....
  • Open it once. This browser is then let in, and the secret part disappears from the address bar.
  • Started rehub a while ago? Press Ctrl-C and run rehub web again for a new link.
